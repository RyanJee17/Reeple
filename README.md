# Reeple

Repo lié au projet de MyDigitalStartUp Reeple, assistant numérique en conseil de jeux de société

## Vendeur Dashboard Design

Il s'agit d'un ensemble de codes pour la conception du tableau de bord Vendeur. Le projet original est disponible à l'adresse https://www.figma.com/design/V9X59EsaXYTExJgcPNuqdR/Vendeur-Dashboard-Design.

## Running the code

Lancer `npm i` pour installer les dépendances
Lancer `npm run dev` pour lancer le serveur de dev.
